# Code of conduct

This project is a room full of people who are just meeting.

- Be curious. Ask about the work before you ask for anything else.
- Be helpful. Review, explain, and leave things clearer than you found them.
- Be kind. Disagreement about code is fine. Insults, harassment, and creepy comments are not.
- Keep personal data out. No email addresses, phone numbers, student IDs, or résumés in profiles or issues.
- Participation is optional.

If something feels off, contact Michael Stringham, the maintainer of this repository.
